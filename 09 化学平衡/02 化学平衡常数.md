## 一、浓度商（Q）
1. 定义：在可逆反应的任意时刻（包括反应进行中、未达平衡状态），生成物浓度幂之积与反应物浓度幂之积的比值，称为浓度商。它是判断反应进行方向的关键物理量，仅与反应体系的瞬时状态相关。
2. 表达式：对于一般可逆反应：$aA(g) + bB(g) \rightleftharpoons cC(g) + dD(g)$（A、B为反应物，C、D为生成物，a、b、c、d为化学计量数），浓度商的表达式为：  
$Q_c = \frac{[C]^c \cdot [D]^d}{[A]^a \cdot [B]^b}$  
- 式中$[A]$、$[B]$、$[C]$、$[D]$分别为反应进行到某一时刻A、B、C、D的瞬时浓度（单位：mol/L）；  
- 若反应体系中有固体（如C(s)）或纯液体（如H₂O(l)），因其浓度视为常数1，不代入表达式，例如反应$CaCO_3(s) \rightleftharpoons CaO(s) + CO_2(g)$的浓度商为$Q_c = [CO_2]$。
3. 注意事项：
   - 表达式中浓度为任意时刻的瞬时浓度，非平衡浓度。
   - 固体、纯液体的浓度视为常数，不列入浓度商表达式。若误将固体浓度代入，会导致Q值计算错误，进而误判反应方向。
   - Q的表达式必须与化学方程式的书写形式严格对应，计量数不同，Q的表达式和数值均不同。例如：
     
     反应①$N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)$，$Q_1 = \frac{[NH_3]^2}{[N_2] \cdot [H_2]^3}$；
     
     反应②$\frac{1}{2}N_2(g) + \frac{3}{2}H_2(g) \rightleftharpoons NH_3(g)$，$Q_2 = \frac{[NH_3]}{[N_2]^{1/2} \cdot [H_2]^{3/2}}$；
     
     同一时刻的浓度代入时，$Q_1 = (Q_2)^2$，与K的对应关系也需匹配方程式。
   - 计算Q时，各物质浓度（或分压）的单位必须统一（如浓度均用mol/L，分压均用Pa），且需与平衡常数K的单位对应。若单位不统一，会导致Q与K的数值无法直接比较。
   - Q反映的是整个反应体系的瞬时状态，若体系中存在多种反应（如平行反应、连续反应），需分别针对每个可逆反应单独计算Q，不可混淆不同反应的物质浓度。
   - 比较Q与K时，二者需为同一类型（均为浓度平衡常数$Q_c$与$K_c$，或均为压力平衡常数$Q_p$与$K_p$），不可将$Q_c$与$K_p$直接对比，需先通过$K_p = K_c \cdot 
     (RT)^{\Delta n}$换算后再比较。
   - Q仅用于判断非平衡状态的反应方向，若体系已达平衡（Q=K），则Q值不再变化；平衡移动过程中，Q会随浓度（或分压）的改变而实时变化，直至重新等于新条件下的K。
  4. 用途（判断反应进行方向）
     通过比较浓度商（Q）与化学平衡常数（K）的大小，可直接判断可逆反应的进行趋势：
- 若$Q < K$：反应正向进行（生成物浓度需增大，反应物浓度需减小，直至Q=K）；
- 若$Q = K$：反应达到平衡状态（正、逆反应速率相等，各物质浓度不再变化）；
- 若$Q > K$：反应逆向进行（反应物浓度需增大，生成物浓度需减小，直至Q=K）。

## 二、化学平衡常数（K）
### （一）定义
温度一定时，可逆反应达到化学平衡状态时，生成物浓度幂之积与反应物浓度幂之积的比值为定值，该定值即为化学平衡常数（简称平衡常数）。

### （二）表达式
#### （1）浓度平衡常数（$K_c$）
针对气体或溶液中的可逆反应，以浓度为基准，表达式与浓度商一致，但需注意：仅平衡时的浓度可代入计算。  
对于反应$aA(g) + bB(aq) \rightleftharpoons cC(g) + dD(l)$，平衡常数表达式为：
$K_c = \frac{[C]^c}{[A]^a \cdot [B]^b}$（D为纯液体，不代入）

#### （2）压力平衡常数（$K_p$）
针对有气体参与的可逆反应，以各气体的平衡分压为基准（分压：混合气体中某组分的压力，等于总压×该组分的物质的量分数）。  
对于反应$aA(g) + bB(g) \rightleftharpoons cC(g) + dD(g)$，$K_p$表达式为：  $K_p = \frac{p_C^c \cdot p_D^d}{p_A^a \cdot p_B^b}$  
- 式中$p_A$、$p_B$、$p_C$、$p_D$为各气体的平衡分压（单位：Pa或atm）；  
- $K_c$与$K_p$的换算关系：$K_p = K_c \cdot (RT)^{\Delta n}$，其中$R$为气体常数（8.314 J·mol⁻¹·K⁻¹），$T$为热力学温度（K），$\Delta n = (c + d) - (a + b)$（气体生成物化学计量数之和 - 气体反应物化学计量数之和）。

### （三）单位
平衡常数的单位由反应方程式中各物质的化学计量数决定，无固定值【具体取决于表达式中浓度（或分压）的幂次差】：
- 如：反应$H_2(g) + I_2(g) \rightleftharpoons 2HI(g)$，$\Delta n = 2 - (1 + 1) = 0$，$K_c$无单位；  
- 如：反应$N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)$，$\Delta n = 2 - (1 + 3) = -2$，$K_c$的单位为（mol/L）⁻²；  
- 如：反应$2SO_3(g) \rightleftharpoons 2SO_2(g) + O_2(g)$，$\Delta n = (2 + 1) - 2 = 1$，$K_c$的单位为mol/L。  
注意：部分教材或试题中会省略平衡常数的单位，仅保留数值，需结合具体场景判断。

### （四）意义
平衡常数值的大小反映化学反应的进行程度（反应限度）：
- K值越大：平衡时生成物浓度占比越高，反应物转化率越高，反应进行得越彻底（通常$K > 10^5$时，可认为反应几乎完全进行）；
- K值越小：平衡时反应物浓度占比越高，反应物转化率越低，反应进行得越不彻底（通常$K < 10^{-5}$时，可认为反应几乎不能进行）；
- K值在$10^{-5} \sim 10^5$之间：反应处于可逆平衡状态，反应物和生成物共存，转化率适中。
- 注意：\(K\) 仅反映反应限度，与反应速率无关（\(K\) 大不代表反应速率快）。（反应限度是指可逆反应达到平衡时，反应物转化为生成物的最大程度）

### （五）与化学方程式书写形式的关系
平衡常数与化学方程式的书写形式一一对应（同一反应的不同表达形式，K值不同），规律如下：
1. 正逆反应：正反应平衡常数 \(K_{\text{正}}\) 与逆反应平衡常数 \(K_{\text{逆}}\) 互为倒数，即 \(K_{\text{正}} = \frac{1}{K_{\text{逆}}}\)；
2. 系数缩放：化学方程式乘以系数 \(x\)，平衡常数变为原常数的 \(x\) 次方，即 \(K' = K^x\)；
3. 反应叠加：两个方程式相加得到总方程式，总反应平衡常数等于两分反应平衡常数的乘积，即 \(K_{\text{总}} = K_1 \cdot K_2\)。
4.注意：计算或比较K值时，必须先确认化学方程式的书写形式一致。

### （六）影响因素
1. 核心影响因素：温度（平衡常数是温度的函数）：
   - 放热反应（$\Delta H < 0$）：升温，平衡逆向移动，K值减小；降温，平衡正向移动，K值增大；
   - 吸热反应（$\Delta H > 0$）：升温，平衡正向移动，K值增大；降温，平衡逆向移动，K值减小。
2. 无关因素：反应物/生成物的浓度（或分压）、压强（无气体参与或$\Delta n=0$的反应）、催化剂等，只要温度不变，\(K\) 始终不变。

### （七）核心应用
1. 判断反应进行方向：通过比较 \(Q\) 与 \(K\) 的大小判断：
   - \(Q < K\)：反应正向进行（\(v_{\text{正}} > v_{\text{逆}}\)）；
   - \(Q = K\)：反应达到平衡状态（\(v_{\text{正}} = v_{\text{逆}}\)）；
   - \(Q > K\)：反应逆向进行（\(v_{\text{正}} < v_{\text{逆}}\)）。
2. 计算平衡相关量：已知 \(K\) 和初始浓度，可通过“三段式”计算平衡浓度、反应物转化率（转化率（$\alpha$）定义：$\alpha = \frac{反应物转化的浓度}{反应物初始浓度} \times 100\%$）等；
3. 比较反应限度：同一温度下，相同类型的可逆反应，\(K\) 越大，反应进行得越完全。
4. 判断平衡移动方向：当外界条件（如温度、压强、浓度）改变时，先判断Q或K的变化，再通过Q与K的关系判断平衡移动方向
- 温度改变：影响K值，进而导致Q≠K，平衡移动；
- 浓度/压强改变（不影响K）：影响Q值，导致Q≠K，平衡移动。

### （八）补充说明
1. 分压平衡常数（\(K_p\)）：若反应体系为气体，可采用分压代替浓度计算平衡常数（\(K_p\)），其数值与 \(K\) 不同，但意义一致，且仅受温度影响；
2. 多步反应：总反应的平衡常数等于各步反应平衡常数的乘积（总反应=反应1+反应2，$K_{总}=K_1 \times K_2$），可通过该规律计算难直接测定的反应的 \(K\)；
3. 表达式书写：需明确物质聚集状态，仅气体、溶液中的溶质列入，固体、纯液体除外；
4. 平衡常数仅适用于可逆反应，不可逆反应无平衡常数（或视为K→∞）；
5. 表达式中仅代入平衡时的浓度或分压，非平衡状态的浓度/分压只能用于计算Q，不能代入K；
6. K值是温度的函数，使用时必须注明温度，不同温度下的K值不可直接比较。
